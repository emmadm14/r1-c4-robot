# Previous Wheel System

This folder documents the first version of the R1-C4 wheel system developed during the first year of the project.

The mechanical design of this version was mainly developed by **Vladimir Grigoriev**, with integration and testing carried out as part of the R1-C4 project.

## System Principle

The first wheel system used a motor-driven transmission integrated into the robot's side leg.

The mechanism included:

- A DC motor
- A chain transmission
- A driven wheel
- Structural support parts integrated into the leg
- Mechanical interfaces connecting the wheel system to the rest of the robot

This architecture made it possible to obtain an initial functional propulsion system for R1-C4.

## Testing and Limitations

The system was tested on the prototype and was able to drive the robot during the first development phase.

However, the performance was not sufficiently smooth or reliable for continued use.

During testing, the system progressively showed mechanical limitations and eventually became unusable.

This confirmed that the original architecture required a complete redesign in order to improve:

- Reliability
- Mechanical robustness
- Transmission efficiency
- Integration with the chassis
- Overall driving performance

## Documentation

The `images/` folder contains photographs of the previous wheel system and its integration into the prototype.

The `videos/` folder contains a driving test demonstrating the operation of the first version before the system failed.

This previous version is included to document the evolution of the project and provide context for the current redesign of the R1-C4 wheel system.
