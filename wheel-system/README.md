# Wheel System

The wheel system provides the main propulsion of R1-C4 when the robot is operating in its three-wheel configuration.

The system has evolved significantly throughout the project.

## Previous Version

During the first development year, an initial wheel system was developed and integrated into the prototype.

The mechanical design of this first version was mainly carried out by **Vladimir Grigoriev**.

Although the system was functional during early testing, its performance was not sufficiently smooth or reliable, and the mechanism eventually failed.

This highlighted the need for a complete redesign of the propulsion system.

Documentation of this first version is available in:

- `previous-version/`

## Current Redesign

During the second development year, the wheel system is being completely redesigned.

The objective of the new version is to improve:

- Reliability
- Mechanical robustness
- Driving performance
- Integration with the new PETG chassis
- Compatibility with the updated mechanical architecture of R1-C4

The redesign is currently in progress and will be documented in this repository as development continues.
