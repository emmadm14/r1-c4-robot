# Wooden Prototype Chassis

This folder contains photographs of the initial wooden chassis used during the first development phase of R1-C4.

The structure was based on an existing wooden R2-D2-inspired design and adapted to the approximately 3/5 scale selected for the project.

This first chassis provided a practical framework for:

- Validating the overall dimensions of the robot
- Integrating the first mechanical subsystems
- Testing the 2-3-2 transformation mechanism
- Installing the first version of the central-foot lift
- Evaluating the available internal space

Although functional as a prototype, the wooden structure presented several limitations in terms of precision, rigidity and reproducibility.

These limitations motivated the transition toward a redesigned PETG chassis with improved structural strength, dimensional accuracy and modularity.
