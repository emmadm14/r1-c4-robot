# Second Development Phase – Demonstration Videos

This folder contains demonstration videos of the R1-C4 2-3-2 transformation system during the second development phase.

At this stage, the inclination mechanism had already evolved beyond the initial wooden prototype and incorporated improved mechanical components.

## Videos

- **Improved tilt and return test** – demonstration of the robot body tilting and returning to its upright position using the improved 2-3-2 mechanism.
- **Final tilt test** – demonstration of the refined inclination movement.
- **Final return-to-upright test** – demonstration of the mechanism returning the robot body to its upright position.

These videos illustrate the progressive improvement of the 2-3-2 system during the second development phase.
