# Second Development Phase

This folder contains photographs of the second development phase of the R1-C4 2-3-2 transformation system.

After validating the operating principle with the first prototype, the mechanism was progressively refined to improve its mechanical integration and overall quality.

## Mechanical Improvements

One of the main improvements during this phase was the replacement of several temporary wooden components used in the initial prototype.

The linear actuator mounting system was redesigned using dedicated 3D-printed parts, including:

- A 3D-printed linear actuator mount
- A 3D-printed lever arm
- Improved interfaces between the actuator and the body rotation mechanism

These components replaced the earlier wooden prototype parts and provided a cleaner, more reproducible and better integrated mechanical solution.

## Purpose of This Version

The objective of this phase was to move from a proof-of-concept mechanism toward a more refined prototype while preserving the transformation principle validated during the first development phase.

This version also provided experience that would later be used for the current redesign of the chassis and the 2-3-2 system.
