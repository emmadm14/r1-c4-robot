# First Development Phase

This folder contains photographs of the first functional version of the R1-C4 2-3-2 transformation system.

During this development phase, the objective was to validate the mechanical principle of the body inclination mechanism before redesigning the system for improved compactness and integration.

## Prototype Configuration

The first prototype included:

- A linear actuator used to control the body inclination
- A lever mechanism connecting the actuator to the main body axis
- The main rotation shaft and bearing supports
- Integration of the mechanism within the original wooden chassis
- Preliminary electronic control components used during testing

## Purpose of This Version

This configuration made it possible to validate the basic operation of the 2-3-2 transformation mechanism and confirm that the robot body could be tilted using the linear actuator.

Although functional, the first version also highlighted several limitations related to sturdiness and reliability.

These observations were later used to guide the redesign of the chassis and the mechanical systems during the second development phase.
