# First Development Phase

This folder contains images of the first functional version of the R1-C4 central-foot lift system.

The initial mechanism used a belt-driven transmission to actuate the vertical movement of the central foot.

This first version made it possible to validate the basic operating principle of the lift and confirm that the central foot could be deployed and retracted.

However, the mechanism also highlighted several limitations related to compactness, guidance and mechanical integration within the robot.

These observations led to a complete redesign of the lift system during the following development phase.
